# Propuesta TRANSPESA × ASSEGURA AI

Presentación web interactiva del **Diagnóstico Empresarial de Transformación — TRANSPESA**, desarrollada con la metodología AATMF v1.0.

## Visualización

Abra `index.html` en un navegador moderno. La presentación también puede publicarse directamente como sitio estático.

## Controles

- Flechas izquierda y derecha: navegación entre diapositivas.
- `F`: pantalla completa.
- Gestos horizontales: navegación en dispositivos táctiles.
- Botones internos: exploración de hipótesis, unidades de análisis, entregables, roadmap y alcance.

## Alcance

Fleet Intelligence, el ciclo de facturación y TRANSPESA Intelligence Layer se presentan como hipótesis o visión ilustrativa sujetas a validación. No representan resultados del diagnóstico.
